# Security

Report a vulnerability privately through GitHub: open the Security tab of [techneissa/toonval](https://github.com/techneissa/toonval/security) and choose "Report a vulnerability". Please don't open a public issue for it.

toonval reads song files (MIDI, MusicXML, MuseScore) and MIDI input from connected devices; a crash or memory error on a malformed file is in scope.
